How to use this roadmap

Do not wait until you “finish all mathematics” before touching AI. Alternate theory, implementation and projects.

50% understanding, 50% building

For each mathematical concept, implement a tiny version in NumPy or PyTorch. For each major course, build one project without following a tutorial line-by-line.

concept → derive → implement → experiment → explain
Use AI as a tutor, not autopilot

Ask for explanations, hints and code review. For assignments that are meant to teach implementation, attempt the work yourself before asking for a solution.

struggle a little → ask why → retry → verify
RL comes after ML foundations

Stanford CS234 expects Python, calculus, linear algebra, probability/statistics and foundations of machine learning. Treat those as prerequisites, not bureaucracy.

Keep a learning repository

Create one Git repo with folders for notes, NumPy implementations, PyTorch experiments, solved exercises and projects. Your portfolio grows automatically as you learn.
